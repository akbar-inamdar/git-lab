# Git Notes

- Git = version control tool; GitHub = hosts repos online
- Flow: working folder -> git add -> staging -> git commit -> history
- git add selects changes; git commit saves them

## Commands
- git init, git status, git add, git commit -m "msg"
- git diff (see changes), git log --oneline (history)
- git branch (list/create), git switch <branch>, git merge <branch>
- git config --global user.name / user.email

## Concepts
- Branches isolate work; merge brings it back
- Fast-forward: main had no new commits, so the label just moves ahead
- Quote trap: if a line starts with >, press Ctrl+C and retype
